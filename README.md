# خدمة الوكيل — نسخة فعلية (Backend + ChatGPT)

هذه نسخة تشغيل فعلية محلية وليست مجرد واجهة.
المعمارية:
Browser → Flask Backend → PDF processing → optional OpenAI API (ChatGPT) → SQLite → protected downloads

## تشغيل سريع
1. ثبّت Python 3.11+.
2. افتح الطرفية داخل المجلد.
3. نفّذ:
   pip install -r requirements.txt
4. انسخ `.env.example` إلى `.env` وعدّل القيم.
5. شغّل:
   python app.py
6. افتح:
   http://127.0.0.1:5000

## مهم جداً عن ChatGPT
الموقع لا يتصل بحساب ChatGPT الشخصي من داخل الموقع.
حتى يعمل الذكاء الاصطناعي داخل الموقع، تحتاج `OPENAI_API_KEY` من OpenAI API.
إذا لم تضع المفتاح، يبقى الموقع يعمل بالمعالجة المحلية الأساسية، لكن تحليل المقارنة الذكي يحتاج API.

## الدفع
هذه النسخة تستخدم تأكيد دفع يدوي من لوحة الإدارة:
الوكيل يرسل الطلب → الإدارة تتحقق من التحويل خارج الموقع → تضغط تأكيد الدفع → يصبح الملف الكامل متاحاً.
لا ندّعي وجود تحقق مصرفي آلي.

## الخدمات
- ترتيب حسب الأبجدية: PDF واحد، 5,000 IQD.
- المتغيرات والمقارنة: ملف قديم + ملف جديد، 5,000 IQD.
- المعاينة قبل الدفع: الصفحة الأولى فقط مع watermark.
- الملف الكامل لا يظهر للوكيل قبل تأكيد الدفع.

## ملاحظة PDF
الملفات الحكومية/الوكالات قد تحتوي جداول عربية معقدة، وقد تكون بعض الـPDF عبارة عن صور.
لذلك هذه النسخة تحتوي طبقة استخراج نص + معالجة أساسية، ويجب اختبارها على ملفات الوكالة الفعلية قبل اعتمادها تجارياً. يمكن إضافة OCR/table extraction مخصص بعد اختبار عيناتك.
